# LumivIA
LumivIA monitorea en tiempo real las microemisiones de gases nocivos y riesgo de inundación calle por calle mediante visión computacional, generando el primer mapa de salud urbana de la CDMX. Estos datos permiten análisis profundos para planificar zonas en proceso de urbanización, anticipar impactos ambientales y diseñar ciudades más resilientes.
